# رازها (Zite → Settings → Secrets)

| نام | لازم؟ | کاربرد |
|---|---|---|
| `ZITE_BOOTSTRAP_ADMIN_USERNAME` | برای راه‌اندازی | نام کاربری اولین مدیر ارشد. فقط وقتی استفاده می‌شود که هیچ superadmin وجود نداشته باشد. |
| `ZITE_BOOTSTRAP_ADMIN_PASSWORD` | برای راه‌اندازی | رمز موقت همان مدیر. در اولین ورود باید عوض شود. بعد از راه‌اندازی می‌توانید هر دو راز را حذف کنید. |
| `ZITE_AUTH_PEPPER` | اختیاری | رشته‌ی تصادفی که به همه‌ی رمزها اضافه می‌شود. **بعد از ساخت اولین حساب تغییرش ندهید**، وگرنه همه‌ی رمزها نامعتبر می‌شوند. |
| `ZITE_JAMENDO_CLIENT_ID` | برای مرشد | client id جامندو. به `client_secret` نیازی نیست. |

مقدار هیچ رازی در کد، مستندات یا پاسخ API نمی‌آید. صفحه‌ی تنظیمات ادمین فقط «تنظیم شده/نشده» را نشان می‌دهد.
