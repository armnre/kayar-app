# کایار (KAYAR) — همراه ورزشی هوشمند کاپوش

پلتفرم کامل فارسی کایار در یک مخزن: **سایت عمومی + اپ اعضا (مرشد/بدنیار) + پنل مدیریت**
به‌همراه یک **بک‌اند واقعی** (Express + SQLite)، اتصال **هوش مصنوعی به NaraRouter**
(بهترین مدل برای هر جایگاه با سقوط خودکار) و **درگاه پرداخت ایرانی** با ساخت خودکار حساب.

| | |
| --- | --- |
| ورود پنل ادمین | `admin` / `kayar1403` → `/#/admin` |
| ورود اپ اعضا | `kp-1040` / `kayar1403` → `/#/app` |
| اجرای سریع | `npm install && npm run server` → http://localhost:8787 |
| مستندات کامل | [KAYAR.md](./KAYAR.md) |
| راهنمای انتشار و Pull Request | [PUSH-TO-GITHUB.md](./PUSH-TO-GITHUB.md) |

> ⚠️ `server/.env` (کلیدهای واقعی) و پایگاه‌داده هرگز در مخزن/زیپ قرار نمی‌گیرند؛
> از `server/.env.example` کپی بگیر و مقادیر خودت را بگذار.
